# GHK-PESQ • Portal de Resposta de Pesquisas de Qualidade Gehaka

Aplicação frontend independente e ultraleve dedicada para clientes responderem pesquisas de satisfação e qualidade via tokens de acesso criptográficos de 64 caracteres.

## 🚀 Como Executar Localmente

```bash
cd c:\projeto\gehaka\ghk-pesq
npm install
npm start
```
A aplicação iniciará na porta `http://localhost:4205/`.

## 📦 Build de Produção

```bash
npm run build
```
Os arquivos gerados estarão no diretório `dist/ghk-pesq`.
